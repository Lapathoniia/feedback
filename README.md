# Lapathoniia — Feedback & Bug Reports

Тут можна повідомити про баги, проблеми та запропонувати покращення для:

- 💬 **[Lapathoniia Chat](https://app.lapathoniia.top)** — чат з LapaLLM та MamayLM
- 🔌 **[Lapathoniia API](https://api.lapathoniia.top)** — OpenAI-сумісний API
- 🌐 **[lapathoniia.top](https://lapathoniia.top)** — сайт та дашборд

## Як повідомити про проблему

👉 [**Створити нове звернення →**](https://github.com/Lapathoniia/feedback/issues/new)

### Корисно вказати:
- Що робили, що очікували побачити, що сталося насправді
- Модель (LapaLLM / MamayLM / Рада)
- Чи використовували веб-пошук або конектори (Prozorro / Держстат)
- Скріншот якщо є

## Мітки

| Мітка | Опис |
|---|---|
| `bug` | Щось не працює |
| `enhancement` | Пропозиція покращення |
| `chat` | Lapathoniia Chat |
| `api` | Lapathoniia API |
| `website` | Сайт та дашборд |
| `question` | Запитання |
